# MThread Store — устройство

Личный «Play Market» для своих APK без собственного сервера.

## Части

| Часть | Где | Что делает |
|---|---|---|
| Хранилище | Публичный GitHub-репозиторий (по умолчанию `<you>/mthread-store`) | `catalog.json` + `media/` (иконки, скриншоты) в ветке по умолчанию; APK — ассеты GitHub Releases (до 2 ГБ на файл, трафик бесплатный) |
| Админка | `mac/` → `MThread Store Admin.app` | Нативное приложение macOS (SwiftUI). Разбирает APK (aapt2), шифрует закрытые (AES-256-CTR, CommonCrypto), грузит в Releases и коммитит каталог через GitHub API (токен из `gh auth token`). Запросы идут по одному: ≥1,5 с между изменяющими, без автоповторов при ограничениях |
| Клиент | `android/` | Android-приложение: каталог, карточки, установка/обновление в один тап, фоновая проверка обновлений, тихие обновления на Android 12+ |

## Общие настройки

`~/Library/Application Support/MThread Store/store.properties` (вне репозитория): `repo=owner/name`, `key=<64 hex>`. Его создаёт админка при первой настройке; Gradle зашивает `repo` и `key` в BuildConfig клиента.

## Каталог

```json
{
  "schema": 1,
  "updated": "2026-10-30T12:00:00Z",
  "apps": [{
    "id": "com.example.app",            // packageName
    "name": "Example", "short": "...", "description": "...", "changelog": "...",
    "icon": "media/com.example.app/ab12cd34.png",           // путь в репозитории
    "screenshots": ["media/com.example.app/ef56.png"],
    "versionCode": 12, "versionName": "1.2",
    "size": 123456789,                   // размер файла (APK и шифр совпадают — CTR)
    "sha256": "...",                     // SHA-256 исходного APK
    "encrypted": true, "iv": "<32 hex>", // только для закрытых
    "url": "https://github.com/<repo>/releases/download/<id>/<id>-12.apk.enc",
    "updated": "2026-10-30T12:00:00Z"
  }]
}
```

Медиа берутся с `https://raw.githubusercontent.com/<repo>/HEAD/<path>`; имена файлов содержат хеш, поэтому кеш CDN не мешает.

## Шифрование

AES-256-CTR, один ключ на весь магазин, случайный IV на файл. Шифрует админка (результат совпадает с `openssl enc -aes-256-ctr -K <key> -iv <iv>`, 128-битный счётчик); клиент расшифровывает `AES/CTR/NoPadding` потоком прямо в сессию установщика и сверяет SHA-256. Целостность дополнительно гарантирует проверка подписи APK самим Android.

## Установка на телефоне

- Скачивание в `filesDir/downloads` с докачкой (HTTP Range), фоновой задачей WorkManager с уведомлением.
- `PackageInstaller`-сессия: на первой установке — одно системное «Установить?»; обновления приложений, которые поставил Store, на Android 12+ идут без вопросов (`USER_ACTION_NOT_REQUIRED`).
- Раз в 6 часов фоновая проверка каталога → уведомление «Есть обновления»; при включённом автообновлении — тихая установка по Wi-Fi.
- Store может обновлять сам себя: достаточно опубликовать его APK как обычное приложение.

## Ограничения

- Файл в Releases ≤ 2 ГБ.
- Все версии одного приложения должны быть подписаны одним ключом, иначе обновление не встанет.
- Ключ зашит в Store — тот, у кого есть APK магазина, может расшифровать закрытые приложения. Принято осознанно.
